# nomina-de-trabajadores-
Nómina BCV 2.0: Sistema de gestión de nómina que permite administrar trabajadores, controlar salarios y realizar cálculos en dólares y bolívares mediante la tasa de cambio del Banco Central de Venezuela. Incorpora consulta de tasas históricas, conversión automática y compatibilidad con dispositivos Android, ofreciendo una experiencia más práctica,
